# OpenFlow 操作指南

> 面向使用者的前端上手手册。想了解安装 / 部署 / 打包，请看仓库根目录的 [README.md](../README.md)。

OpenFlow 是一个**节点式 AI 工作流画布编辑器**：你在一块画布上摆放「节点」，用「连线」把它们串起来，让上游节点的产出喂给下游节点，从而把「写提示词 → 生成文本 / 图像 / 视频」编排成一条可视化流水线。

## 核心概念（30 秒看懂）

| 概念 | 说明 |
| --- | --- |
| **项目** | 一块独立的画布。可以建多个项目，互不干扰。 |
| **节点** | 画布上的一张卡片。按输出形态分三类：**文本**（Prompt / Any LLM）、**图像**（Image 2 / Nano Banana）、**视频**（Seedance）；外加**素材节点**（拖进来的图 / 音 / 视频文件）。 |
| **连线** | 把上游节点的输出接到下游节点的输入端点。**上游 Prompt 的文字会自动喂给下游生成节点当提示词。** |
| **端点（Handle）** | 节点边缘的小圆点，左侧是**输入**、右侧是**输出**。端点按数据类型着色（文本 / 图像 / 音频 / 视频各一色），**只有类型匹配的端点才能连上**。 |
| **生成是异步的** | 点「生成」后任务在后台跑，**关页面 / 刷新都不会丢结果**——重新打开项目，节点会自动重连、把结果拉回来。 |

## 五分钟快速上手

### 第 0 步：首次进入，填写邮箱前缀（必做）

第一次打开会弹出**阻断弹窗「先填写你的邮箱前缀」**，不填无法进入。

> ⚠️ 弹窗里的红字提醒：*为避免资源滥用，请使用本人百度邮箱前缀登录；频繁切换用户名或使用非邮箱前缀可能触发 IP 封禁，请谨慎操作。*

在**「邮箱前缀」**输入框填你的邮箱前缀（`@` 前面那段，例如 `zhaoqianyu` 或 `v_zhaoqianyu`），点**「开始使用」**即可进入。这个署名（`req_from`）会随所有图像 / 视频生成、文件上传一起发给后端。

### 第 1 步：配置接口地址（用到生成 / Agent 时才需要）

点右上角**「设置」**（齿轮图标），按需填写：

- **「API 接入」**页 → 填 **Agent 接口地址** + **API Key** + **模型名**（画布 Agent 和 Any LLM 节点用这套 OpenAI 兼容接口）。
- **「内网地址」**页 → 填 **AIGC 生成端点 / 图片上传端点 / 音频上传端点**（留空则用服务端默认地址）。

详见 [设置面板详解](#设置面板详解)。

### 第 2 步：新建项目

首页点右上角**「+ 新建项目」**，自动进入这块画布的工作区。

### 第 3 步：做一张「文生图」

1. 从**左侧栏**把**「Prompt 节点」**拖到画布上，在卡片里写下画面描述（例如 *「雨夜霓虹街头的赛博朋克猫」*）。
2. 再拖一个**「Image 2」**（或「Nano Banana」）图像节点到画布上。
3. 从 Prompt 节点**右侧的输出圆点**拉一条线，连到 Image 节点**左侧的「Prompt 输入」圆点**。
4. 点 Image 节点上的**「生成」**按钮。卡片进入「生成中…」，稍后就会显示结果图。
5. 想保存，把鼠标移到结果图上，点右上角的**下载图标**，填个文件名点「下载」即可。

🎉 这就是一条最小工作流。把它换成 Any LLM 节点就是「文本生成文本」，换成 Seedance 就是「生成视频」。

## 基础操作

### 新建 / 打开 / 改名 / 置顶 / 删除项目

- **新建**：首页点**「+ 新建项目」**，立即进入新画布。
- **打开**：点项目卡片任意处。
- **改名**：**双击**卡片上的项目名进入编辑；或进入工作区后**单击顶栏的项目名**编辑。按 **Enter** 保存、**Esc** 取消。
- **置顶**：把鼠标移到卡片上，点**「⋯」**菜单 → **「置顶」**。置顶的项目会带一个图钉标记，并**单独归到首页最上面的「置顶」区**（与其他项目不在同一行）；再点一次**「取消置顶」**即可放回下面。置顶状态存在后端，换设备 / 刷新都还在。
- **删除**：把鼠标移到卡片上，点右上角**「⋯」**菜单 → **「删除」**。

### 添加节点

有两种方式，效果相同：

1. **从左侧栏拖拽**：按住左侧栏里的节点卡片，拖到画布空白处松手，即在落点生成节点（拖拽时有「拖入画布添加  XXX」提示）。
2. **画布空白处右键**：弹出分组节点菜单，点选即在该处添加。

左侧栏 / 右键菜单里的节点清单：

| 分类 | 节点 | 作用 |
| --- | --- | --- |
| **文本** | Prompt 节点 | 写提示词，输出文本 |
| | Any LLM | 把上游文本喂给大模型，产出文本 |
| **图像模型** | Image 2 | 文 / 图生图 |
| | Nano Banana | 文 / 图生图 |
| **视频模型** | Seedance 首尾帧 | 用首帧 + 尾帧生成视频 |
| | Seedance 参考图 | 用参考图生成视频 |

> 💡 还有一个**拉线建节点**的技巧：从某个节点的端点拉出一条线，**松手在空白处**，会弹出节点菜单——选一个节点类型，新节点会**自动创建并连好线**。

### 连线

- 从**源节点右侧的输出圆点**按住拖动，拉到**目标节点左侧的输入圆点**上松手。
- 端点有颜色，**只有同类型（文本↔文本、图像↔图像、音频↔音频、视频↔视频）才能连**，连错类型会被拒绝。
- 连好的线，选中某个节点时，与它相连的线会**高亮并有流动动画**，方便看清上下游关系。

### 移动、缩放与整理画布

- **平移**：在空白处按住拖动。
- **缩放**：滚轮，或用左下角**缩放面板**：`−` / 滑块 / `+`；点**百分比数字**复位到 100%；点**「适配视图」**（Maximize 图标）一键把所有节点收进视野。
- 缩放面板还有两个开关：**「网格吸附」**（磁铁图标，拖动节点自动对齐网格）、**「缩略图」**（地图图标，右下角小地图）。

### 分组 / 整理 / 取消分组

**选中多个节点**（框选，或按住 Ctrl/Cmd 逐个点选）后**右键**：

- **「分组」**：建一个容器把它们包住，可整体移动、给分组改名（点容器上方的「分组名」输入框）。*需选中 ≥2 个非容器节点。*
- **「整理（网格排列）」**：把选中的节点自动排成整齐网格。*需选中 ≥2 个节点。*
- **「取消分组」**：释放容器里的子节点并删掉容器。*需选中 / 右键点中一个分组容器。*

### 复制 / 删除节点

把鼠标移到任意节点上（或选中它），卡片**头部右侧**会出现两个按钮：

- **复制**（「复制节点」）：在原节点**正右侧**生成一份副本，保留参数与结果快照（不含运行中状态）。
- **删除**（「删除节点」）：移除该节点。

## 各类节点怎么用

### Prompt 节点（文本）

最基础的「写提示词」节点。

- 在卡片的文本框里写内容（占位提示「在这里写 prompt…」）。
- **左侧输入端点、右侧输出端点**：输出的文字可连给下游任意生成节点当提示词。
- 若把另一个 Prompt / LLM 节点连到它**左侧的输入端点**，两段文字会**拼接**（形成 Prompt 链）。
- 卡片底部两个按钮：
  - **「选用预设」**：从 [Prompt 预设库](#prompt-预设库) 里挑一条，**替换**当前文本。
  - **「存为预设」**：把当前文本存进预设库（下次任意项目都能复用）。

### Any LLM 节点（文本）

把上游文本发给一个 OpenAI 兼容大模型，产出文本；输出还能继续当下游节点的提示词。

**端点**（左侧从上到下）：
1. **Prompt 输入**（必填）
2. **System Prompt 输入**（可选，接一个 Prompt 节点当系统提示词）
3. **图像 / 音频 / 视频 输入**（可选，做多模态理解——见下）
4. 右侧：**文本输出**

**多模态输入**：卡片上有一行**「Add Input:」**加号按钮（图像 / 音频 / 视频三个图标），点一下就新增一个对应类型的输入端点，再把[素材节点](#素材节点拖文件上传)或上游生成结果连上去，模型就能「看图 / 听音 / 读视频」。

**运行**：点**「运行」**。带思考的模型会显示「思考中…」，否则「生成中…」。出结果后：
- 卡片展示回答，右上角有**复制**按钮。
- 若模型返回了思考过程，会折叠在**「思考过程」**里，点开可看。

**模型 / 温度 / 思考开关**在右侧 [Inspector](#右侧-inspector-参数面板) 里调。

### 图像生成节点（Image 2 / Nano Banana）

- **端点**：左侧「Prompt 输入」（必填）+ 可选的图像输入（用「Add Input:」加）；右侧「图像输出」。
- **提示词**来自上游连线的 Prompt 节点。
- **输入图**来自连线（上游[图像素材](#素材节点拖文件上传)或别的图像节点的结果）——**没有输入图就是纯文生图**，有输入图就是图生图。
- 参数（尺寸 / 质量 / 张数，或 Nano Banana 的 version / 宽高比 / 尺寸）在右侧 Inspector 调。
- 点**「生成」**，出结果后鼠标移上去、点右上角**下载图标**可保存。多张结果会平铺成网格。

### 多角度节点（换个机位重拍一张）

给一张已有的图**换相机角度**：向左/右环绕、升高俯视或降低仰视、推近拉远，生成调整视角后的新图。

- **端点**：左侧「Assets」资源端点（**必填**，连源图）+「Prompt」端点（可选，附加描述）；右侧「图像输出」。
- **源图**来自连线（[图像素材](#素材节点拖文件上传)或上游图像/多角度节点的结果）。**恒只用一张**：连了多张时默认用第一张，可在上游 Prompt 里 **@** 指定用哪张。
- **调角度**在右侧 [Inspector](#右侧-inspector-参数面板)：
  - **摄像头轨道球**——球心是源图，球面上的小相机就是机位。**直接拖球面**环绕/升降相机，或点四缘**箭头**每次走 15°；左下角实时显示当前读数，右上「复位视角」一键归零。
  - **三根滑杆**——旋转（-180~180°，负=向左）/ 倾斜（-90~90°，负=仰视）/ 缩放（近景·中景·远景）。
- 生成模型默认 **Nano Banana**（可切 Image 2），角度会被翻译成一段**英文相机指令**连同源图发给模型（模型对英文摄影术语的执行更精准；指令是英文不影响你用中文写附加要求）；连上 Prompt 节点的话，文本会作为「Additional requirements」拼在指令后（比如“保持人物手里的伞不变”）。
- 点**「生成」**出新视角图，之后可以：串下一个多角度节点继续转、当输入图喂给图像/视频节点、或直接下载。

> 实际发出的相机指令可在 Inspector 底部的**「请求」预览**里看到，调滑杆时它会实时变化。

### 视频生成节点（Seedance）

有两个变体（建节点时选，卡片标题会标「首尾帧」或「参考图」）：

- **Seedance 首尾帧**：左侧有固定的**「首帧」**和**「尾帧」**两个图像输入端点，各连一张图，生成一段从首帧过渡到尾帧的视频。
- **Seedance 参考图**：用「Add Input:」加图像输入端点，连参考图生成视频。

两者都可选接**音频输入**（连[音频素材](#素材节点拖文件上传)当配音）。提示词同样来自上游 Prompt 节点。参数（version / 分辨率 / 宽高比 / 时长）在 Inspector 调。点**「生成」**，结果是带播放控件的视频，可下载。

> 视频节点右侧的**视频输出**还能连到 Any LLM 节点的视频输入端点，做「让大模型理解这段视频」。

### 素材节点（拖文件上传）

**上传资源只有一种方式：把文件从桌面拖到画布空白处。**

- 支持**图像 / 音频 / 视频**文件（拖入其它类型会提示「仅支持拖入图像 / 音频 / 视频文件」）。
- 松手后在落点生成一个**素材节点**，后台自动上传（上传中显示骨架占位，成功后显示缩略图 / 播放器）。
- 素材节点是**纯「源」节点**（只有右侧输出端点），把它连到下游节点的对应输入端点即可：
  - 图像素材 → 图像 / 视频节点的图像输入，或 Any LLM 的图像输入。
  - 音频素材 → Seedance 的音频输入，或 Any LLM 的音频输入。
  - 视频素材 → Any LLM 的视频输入。

## 右侧 Inspector 参数面板

**当你恰好选中一个图像 / 视频 / Any LLM 节点时**，画布右侧会出现 Inspector 面板（节点卡片本身只显示结果，参数都在这里调）。面板左缘可拖拽调宽。

- 顶部显示该节点的**模型名**。
- 中部是**按节点类型不同的参数控件**：
  - **图像（Image 2）**：尺寸 / 质量 / 张数。
  - **图像（Nano Banana）**：version / 宽高比 / 尺寸。
  - **多角度**：摄像头轨道球 + 旋转 / 倾斜 / 缩放滑杆 + 复位视角 + 模型选择（参数区随所选模型切换成上面两套之一）。
  - **视频（Seedance）**：version / 分辨率 / 宽高比 / 时长（秒）。
  - **Any LLM**：**Model**（下拉，选项后带能力图标标注是否支持 思考 / 图像 / 音频 / 视频；旁边有**「刷新」**按钮重新从端点拉模型列表）、**Temperature** 滑块、**Thinking（思考）** 开关。
- **图像节点**还会显示「输入图（来自连线）」的只读预览；没有输入图时提示你「把图片拖到画布空白处会生成『图像素材』节点，连线到本节点即可作输入图」。
- 底部是**「请求（上游实发）」**预览——点击「生成」时实际发出去的请求体，可在 **JSON / 表格** 两种视图间切换。想确认「到底发了什么」时很有用。

## 画布 Agent：一句话生图

不想手动摆节点？用自然语言让 Agent 帮你建。

1. 点画布**右下角的悬浮按钮**（机器人图标）打开**「画布 Agent」**面板。
2. 在输入框（占位「描述你想要的画面…」）里说你想要什么，例如 *「帮我画一只在雨夜霓虹街头的赛博朋克猫」*。**Enter** 发送，**Shift+Enter** 换行。
3. Agent 会理解需求、自动在画布上**建好「Prompt 节点 → 图像节点」并连线、开始生成**，并回一句「已在画布创建 N 组节点并开始生成」。
4. 生成结果会直接显示在新建的图像节点上。

> Agent 建的节点和你手动建的完全一样：可以再改 Prompt、换模型、点「生成」重跑。
> 面板头部的**「收起」**可关掉面板（偏好会记住）。使用前需在[设置 → API 接入](#设置面板详解)里配好 Agent 接口。

## Prompt 预设库

全局共享的常用提示词库，跨项目通用，分**「常用 Prompt」**和**「System Prompt」**两组。

- **打开**：顶栏（或首页）的**「预设」**按钮。
- **管理**：在弹窗里新增 / 编辑 / 删除预设（选分组、填标题和正文）。
- **使用**：在任意 **Prompt 节点**卡片点**「选用预设」**一键填入；或写好内容后点**「存为预设」**收藏起来。

## 下载结果

图像 / 视频结果卡片上，鼠标移上去会出现**下载图标**。点开后弹出**「下载文件」**对话框：

- 只需填**文件名**（不含扩展名），**扩展名会按文件类型自动补**（图像 `.png`/`.jpg`，视频 `.mp4` 等）。
- 点**「下载」**（或按 Enter），浏览器即开始下载。

## 设置面板详解

顶栏（或首页）**「设置」**按钮打开，左侧分三页：

### 常规
- **邮箱前缀（req_from）**：图像 / 视频生成与文件上传的调用方署名。就是首次进入时填的那个，可在此修改。

### API 接入（画布 Agent 与 Any LLM 节点共用）
- **接口协议**：按网关实际支持的接口选 `Responses API`（`POST /v1/responses`）或 `Chat Completions`（`POST /v1/chat/completions`），默认前者。
- **Agent 接口地址**：填基础地址即可（如 `https://host/v1`），系统按上面选的协议自动补 `/responses` 或 `/chat/completions`；地址里已经带了另一种后缀也会自动换掉。
- **Agent API Key**：密码框，**写入-only**——不回显；留空表示保持已存的值不变（无鉴权网关可留空）。
- **Agent 模型名**：下拉选择。候选来自两处并集——
  - 下方**「模型列表（手动维护，每行一个）」**里你手填的模型；
  - 点**「获取模型列表」**从端点 `GET /models` 动态拉取的模型（不支持该接口的网关，靠手填列表也能得到下拉）。
- **测试连接**：点一下发一条最小请求，验证接口 / 密钥 / 模型是否可用（成功会显示「连接成功 · 模型 X · 延迟」）。

### 内网地址（留空则用服务端默认）
- **AIGC 生成端点（图像 / 视频）**
- **图片上传端点**
- **音频上传端点**

改完点右下角**「保存」**。

## 常见问题（FAQ）

**Q：点了「生成」，关掉页面结果会丢吗？**
不会。生成是后台异步任务，重新打开项目后节点会自动重连、把结果拉回来展示。

**Q：为什么连不上线？**
端点按数据类型着色，只有**同类型**才能连（比如图像输出只能连图像输入）。确认你连的是对应颜色 / 类型的端点，且是从**输出（右）**连到**输入（左）**。

**Q：图像 / 视频节点怎么加输入图？**
不能在节点或 Inspector 里上传。请**把图片文件拖到画布空白处**生成「图像素材」节点，再**连线**到目标节点的图像输入端点。

**Q：Any LLM / 画布 Agent 报「请在设置中填写」？**
说明还没配 Agent 接口。到**设置 → API 接入**填好接口地址、Key、模型名，点「测试连接」确认可用。

**Q：生成一直失败？**
先在 Inspector 底部的**「请求（上游实发）」**看看实际发出的请求对不对；再核对**设置**里的端点地址、`req_from` 署名是否填了、模型名是否正确。节点底部通常会内联显示具体错误信息。

**Q：怎么快速对齐一堆乱摆的节点？**
框选它们 → 右键 → **「整理（网格排列）」**。
